# Finday

日程調整もできる部室表

日程調整プログラムと部室予約プログラムをシームレスに結合し、サークル活動などにおける日程調整と部屋予約の手間を軽減することを目的に開発されたWebアプリケーションです。

---

## 使用方法

本アプリケーションは各自でレンタルサーバーなどにデプロイして使用します。そのデプロイ方法をここでは説明します。

### 動作環境

まずは以下に示す動作条件を満たすVPSやレンタルサーバーをご準備ください。

> 基本的にはWordPressが動作するような環境で、CLIでのコマンドが実行できれば問題ないと思います。

**動作条件**

- PHPのバージョン8.2以上が使用可能であること
- MySQLなどのデータベースが使用可能であること
- サーバーの公開ディレクトリに自由にファイルを配置できること
- SSHやサーバーコンソールなどCLIでコマンドが実行できること
