## ログイン後

- **[GET] `/`** -> [GET] `/menu`にリダイレクト
- **[GET] `/menu`**: メニューの表示
    - 選択できる項目は以下の通り（「タイトル」：説明 -> 押した際のルーティング）
        - 「予約を取る」：部屋の予約状況の閲覧と部屋の予約ができます -> [GET] `reservation`
        - 「日程調整をする」：バンド内で日程調整ができます -> [GET] `schedule`
        - 「バンドの管理をする」：自分が所属する登録や削除、バンドの作成ができます -> [GET] `band`
        - 「登録情報の変更」：名前やパスワードの変更、アカウントの削除ができます -> [GET] `profile`
    - それとは別に管理者がアプリケーション管理画面へ遷移するボタンを追加する -> [GET] `admin`
        - 管理者権限を持っていない場合は[GET] `menu`に遷移。画面上部にその旨のメッセージを表示

### 部屋予約

- **[GET] `/reservation`**: 部屋の空き状況を表示する画面
- **[GET] `/reservation/{reservations.id}`**: 部屋の予約の詳細情報を表示
- **[GET] `/reservation/create`**: 部屋の予約登録画面の表示
- **[POST] `/reservation/create`**: 部屋の予約登録実行
